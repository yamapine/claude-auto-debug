## 元仕様書から変更した点（理由）

1. **インパルス判定**: 「ROC(%) ≥ ATR(価格)×3」は単位が違うので比較できない → `|close[レンジ長] − close[レンジ長+N]| ≥ ATR × 3`（4H足）に変更。
2. **レンジ判定の足**: 仕様書は15分足40本だが、動画は4H足で「何日もレンジ」→ 4H足で直近12本の高値−安値幅 ≤ ATR(50)×3 で判定。
3. **VAH/VALのリペイント**: 今週の形成中VPは週中に値が変わる → **確定済みの先週・2週前のみ**を使用。
4. **VPの計算**: 内蔵VPや公開スクリプトの値はPineから読めない → チャート足のOHLCVを価格ビンに配分して自前で計算（近似。内蔵VPとは数値がずれる）。
5. **TPの位置**: インパルス直前の安値／高値（4H足で `lowest/highest(N+1)` をレンジ開始時点で取得）。
6. **SL**: `max(VAH, シグナル足高値) + ATR(15分,14)×1.5`（ショート）。足の高値がVAHを超えている場合でもSLが近すぎないようにするため。
7. **反発トリガーの定義**: 許容幅内でVA線にタッチ → 線の内側で確定 → 陰線（ショート）／陽線（ロング）。
8. **無効化**: 実体が VA線 ± ATR×1.5 を抜けて確定 / TP到達 / 192本経過。
9. **ニュースフィルター**: Pineは経済指標の発表時刻を取得できない → 時間帯で代用（初期値: 金曜21:00–23:59 JST）。

## 既知の制約

- 動画で紹介された成績（世界大会）は本人の自己申告＋大会成績であり、この手法のバックテスト結果ではない。
