# 事前登録：GVZアラートの設計（いつの値・上昇・境目）— 2026-10-22

この文書をコミットしてから計算する。データは `PREREG_GoldVol_Forecast_20261022.md` と同じ日足CSV（XAUUSD・GVZ）。

## 背景
前回の検証で月末のGVZを使ったのは、月ごとに評価する都合で決めただけで、根拠はない。「過去3年の上位」という境目にも根拠はない。

## 定義
- 日次TR% = 真の値幅 ÷ 前日終値 × 100
- **将来RV(d)** = 日 d の翌営業日から21営業日分の日次TR%の平均（予測する対象）
- 予測は最小二乗。推定期間は 2008-08〜2011-12 で固定し、評価は **2012-01〜2023-12**。サブ期間は 2012-15 / 2016-19 / 2020-23
  - 評価期間中には推定し直さない。日次データは重なりが大きいので、拡大ウィンドウより単純にする
- 説明変数：L = log GVZ(d)、C = log GVZ(d) − log GVZ(d−21営業日)（＝1か月前より上がったか）

## Q1 いつの値を使ってもよいか
- 全営業日で予測したときの MSE（全日）と、月末の営業日だけの MSE（月末）を、モデル L で比べる
- **判定**：MSE（全日）≤ MSE（月末）× 1.10 なら「毎日の値で判断してよい」（日次アラートにできる）

## Q2 「1か月前より上がった」に意味はあるか
- モデル L と L+C を、全営業日で比べる
- **判定**：MSE(L+C) ≤ MSE(L) × 0.95 かつ、3サブ期間中2つ以上で L+C < L なら、上昇（C）をアラートに入れる
- 参考：C 単独の MSE。C>0（上昇中）と C≤0 に分けたときの将来RVの平均

## Q3 境目の決め方
- EAの損益はボラの絶対水準で決まる（コスト0.50 USD/oz は固定なので、値幅が小さいとコストに負ける）。そのため境目は「過去3年の順位」ではなく、**GVZの値そのもの**で決める
- 手順：2022-08〜2026-10 の月ごとに、EAの建玉時 ATR%（M15）の中央値を、同じ月の GVZ 終値の平均で回帰する（log-log）。ATR% 0.15 / 0.20 に当たる GVZ を求める
  - ATR% 0.15 = EAの月次損益が平均でほぼゼロを超える帯の下限、0.20 = はっきりプラスの帯（`SVF_VolDrivers_20261022.md` §1）
- **注意**：ATR%の帯は、2024〜26年のEA成績を見てから決めたもの（事後）。境目は「目安」とし、BTの合否には使わない。フォワードで確認する
