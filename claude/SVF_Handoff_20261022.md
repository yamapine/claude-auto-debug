### Sweep v1.5 の機能（インジ・発注なし）
- EAと同一エンジン（CSvfEngine）で多条件を並列計算（エンジンは計算系ごと1本、条件ごとに状態を差し替えて Commit）
- 計算系最大4（各々MAタイプ指定）：既定 V1 VWMA+BB / V2 SMA+BB / V3 値幅(TR)加重+BB / V4 対数ティック出来高加重+BB（全て50/3/50）
  - エンジンに MAタイプ 7=TRWMA_BB, 8=LVWMA_BB を追加（既存タイプは不変を確認済み）。※EA側エンジンには未反映
- 条件格子：Z1〜5 × BB復帰4種 × SL(なし/1.5/2.5/4/5) × 両方向 = 100/MA
- フィルター（新規を見送る or 変形）：ATR%下限、相対ボラ、指標前/前後回避、H1/H4順張り、指標前フラット、指標後回避、**低ボラ反転（v1.5）**。比較対象「全条件」が既定
- 出力（MQL5\Files）：`SVF_Sweep_*.csv`（条件別・年別 y2024_n/net/pf…）、`SVF_Monthly_*.csv`（idx, ym, n, net, gp, gl）、`SVF_Trades_*.csv`（基準=V1・F0の取引ログ、建玉前特徴量つき）
- 既定入力：集計開始 2024-01-01 / 前後半境界 2025-01-01 / コスト0.50 / 次足始値（※v1.3初版は2026・0.30のままでユーザーが再実行した経緯あり → 受領時に cond 列の cost と y2024 列の有無を必ず確認）
- 経済カレンダー：CalendarValueHistory（サーバー時刻、USD・重要度高・時刻確定のみ）。ユーザー環境で2022-08から取得できた

### 検証方法（コード改修時に毎回実施）
- mq5 からエンジン〜シミュレーション部分を正規表現で抽出して C++ ヘッダ化（MQLの配列→std::vector、TimeToStruct等をシム）
- 実データ：Yahoo GC=F 15分足（約4.5千本）・1時間足（約1.4万本、2年）。指標時刻は合成（火水金 12:30/14:00 UTC）
- チェック：①旧版との回帰（全集計一致）②独立実装の参照コードと全条件一致（両約定モード）③不変量（常に許可=F0、全見送り=0件、全反転=−F0−2n×コスト 等）④先読みチェック（データ打ち切りで値不変）⑤新しい計算（TR加重MA等）はPython独立計算と照合

## 4. これまでの結果（全てBT値）
1. **ボラ帯分析（事後）**：低ボラ（ATR%<0.14）はコスト前から赤字（PF0.77、SL率38〜49%、勝率31〜37%）。主因は順張りシグナルの空振り。コストはATR比で低ボラ約20%・高ボラ約4%。低ボラ帯は売買反転でPF1.19〜1.22（事後・未検証→v1.5で検証中）。0.20〜0.25帯の赤字は5件のSL負けが83%（ばらつき）
2. **v1.2 フィルター（基準のみ）**：SMA+BBでATR%≥0.16採用候補 → VWMA+BBでは不採用。両MAで①②③を満たすのはATR%≥0.14のみ
3. **v1.3 全条件**：全フィルターが判定B不合格（ATR%の①通過率4〜41%≒偶然）。指標前フラットは2026利益を約7割削り棄却（発表をまたぐ保有が利益源）。MAはVWMA+BB維持（TR加重はDD411と有望だが基準未達）
4. **重要所見**：現行EA設定は2026年に合わせ込まれた可能性（100条件中 2026=6位、2024=48位、2025=80位。近傍の2026成績は−1,741〜+2,388）。現行設定は `OBV_Z_Sweep_Result_20261020`（2026データのみ）から選定された経緯
5. **固定WF（2024-25で選定→2026）**：R1/R2/R3 すべて合格（R1: SMA+BB・ATR%≥0.14・Z5・ドテン+ロック・SL2.5 → 2026 PF1.94）。年単位の成績相関は負（2024→2025 ρ=−0.27、2025→2026 ρ=−0.24）＝去年の勝ち設定は翌年負けやすい。2年とも崩れない設定は2026もやや良い（ρ=+0.15）
6. **ローリングWF（PREREG）**：上位10平均で 1・6・12か月が合格、3か月不合格（非単調）。統計的には弱い（1か月のみ p=0.037、補正後非有意）。**PBO=0.46**（IS最良はOOSで約9割縮小）
7. **方法数1/2/4（事後）**：振り返り1か月が方法数によらず両年プラス・DD小。**4方法・1か月：21か月 +1,568（2025 +709 / 2026 +859）、最悪月−111、最大DD244**。月単位では成績が続き、年単位では逆転
8. **ボラの効果は全条件共通**：月のATR%と全条件平均損益 ρ=+0.42。ただし高ボラ月でもプラス条件は52%のみ
