# 事前登録：来月の金のボラを前もって当てられるか — 2026-10-22

この文書をコミットしてから計算する。結果が悪くても基準は変えない。

## 1. 問い
月末の時点で分かる情報（今月の実現ボラ・GVZ・VIX）で、**来月の XAUUSD の実現ボラ** を当てられるか。どの指標を察知の仕組み（Pine インジ）に入れるかを決める。

## 2. データ（TradingView から書き出した日足CSV、2026-10-22受領）
- OANDA:XAUUSD（1988〜）、CBOE:GVZ（2008-08〜）、TVC:VIX（1990〜）
- 使う月：2008-08〜2026-09（2026-10は途中までなので除外）

## 3. 定義
- **実現ボラ RV（月）** = その月の日足の「真の値幅 ÷ 前日終値 × 100」の平均（%）。真の値幅 = max(高値, 前日終値) − min(安値, 前日終値)
- **GVZ・VIX（月）** = その月の最後の終値
- 予測するもの：**log RV(t+1)**
- 予測モデル（最小二乗。毎月、その月までに分かっているデータだけで推定し直す＝拡大ウィンドウ、最初の推定は36か月分）
  - M0：過去平均（比較の基準）
  - M1：log RV(t)
  - M2：log GVZ(t)
  - M3：log RV(t) + log GVZ(t)
  - M4：log RV(t) + log GVZ(t) + log VIX(t)

## 4. 評価期間
- **主評価：2012-01〜2023-12（144か月）**。サブ期間：2012-15 / 2016-19 / 2020-23
- 参考（判定に使わない）：2024-01〜2026-09。この期間の金のボラ（ATR%）はEAの分析で既に見ているため

## 5. 判定基準（主評価期間で判定）
- **R1 続く性質は使えるか**：M1 の予測誤差（log の二乗誤差の平均、MSE）が M0 より小さい。かつ3サブ期間すべてで小さい
- **R2 GVZ を足す価値**：M3 の MSE ≤ M1 の MSE × 0.95。かつ3サブ期間中2つ以上で M3 < M1
- **R3 VIX を足す価値**：M4 の MSE ≤ M3 の MSE × 0.95。かつ3サブ期間中2つ以上で M4 < M3
- 採用の決め方：R1 が合格なら RV をインジに入れる。R2 も合格なら GVZ を入れる。R3 も合格なら VIX を入れる。不合格の指標は表示しても判断には使わない

参考（判定に使わない）
- 高ボラ月の的中率。高ボラ月 = 来月の RV が、その時点までの過去36か月の RV の上位1/3以上の月
- 手元のEA月次損益（2024〜）と予測ボラの関係
