# 結果：GVZアラートの設計 — 2026-10-22

事前登録：`PREREG_GVZ_Alert_20261022.md`（commit 8dacf12 で基準を固定してから計算）
再現：`claude/analysis_vol/gvz_alert.py`。評価：2012-01〜2023-12（日次）

## Q1 月末の値でないといけないか → **毎日の値でよい（合格）**
- 来月（21営業日）の荒れ具合の予測誤差：全営業日 0.0418 / 月末の営業日だけ 0.0420（比 0.99）
- → アラートは毎日の値で出してよい

## Q2 「1か月前より上がった」に意味はあるか → **ほぼ無い（不合格）**
- GVZの水準だけ 0.0418 → 水準＋上昇 0.0413（改善1.3%。基準は5%以上）
- 上昇だけで予測すると誤差 0.192（水準だけの約4.6倍）＝ **大事なのは「今どれだけ高いか」**
- 参考：GVZ が上位1/4（19以上）の中では、上昇中の方が来月の値幅がやや大きい（1.80% vs 1.59%）。表示はするが、判断には使わない

## Q3 境目の決め方 → **GVZ 17 / 22（EAのコストから逆算した目安）**
- 月ごとの EAの ATR%（M15）と GVZ の相関 0.92（2022-08〜2026-10、51か月）
- ATR% 0.15 ↔ **GVZ 17.1**、ATR% 0.20 ↔ **GVZ 22.3**
- 「過去3年の順位」をやめた理由：コストは0.50 USD/oz で固定なので、EAが勝てるかどうかは値幅の絶対的な大きさで決まる。順位にすると、低ボラが続いた時期でも「上位」と判定してしまう
- 注意：ATR%の帯は2024-26年のEA成績を見て決めたもの（事後）。境目は目安で、フォワードで確認する
- 参考：2012-23年の GVZ の中央値は 16.1。17以上は「普段より少し荒れている」水準

## プロのやり方（調査）
| やり方 | 中身 | こちらでの扱い |
|---|---|---|
| 予想変動率の水準で局面を分ける | VIXやGVZの帯ごとに、使う戦略を切り替える／新規を止める。境目は人によってバラバラ（VIX 13/20、25、32 など） | 採用。境目は自分のデータ（EAのコスト）から決めた |
| 平均からの乖離（Zスコア）で判定 | 過去252日の平均・標準偏差に対して何σ高いかを見る | 不採用。今回の検証で「相対的な上昇」はほぼ効かなかった |
| ボラの方向（上昇中か） | 予想変動率の短期EMAで上昇・下落を見る | 参考表示のみ（Q2 不合格） |
| ボラに合わせてロットを調整（ボラ・ターゲティング） | ボラが高いほどロットを減らし、1回の損失額をそろえる。CTA（先物ファンド）の研究では年0.5〜0.8%の改善、リスクのばらつきも減る | 次の検討課題。荒れた局面では値幅が広がるので、ロットを増やさず「1回の損失額を固定」が基本 |
| 予想変動率の期間構造（短期 > 長期 = 本物のパニック） | VIX9D > VIX を急変の確認に使う | 金では該当する指数がTradingViewにあるか【わかりません】 |

## 追記：GVZ帯の効果は全条件で共通か（参考・事後、`analysis_vol/gvz_all_conditions.py`）
2024-01〜2026-09、前月末GVZで月を3つの帯に分類（17未満 13か月 / 17〜22 9か月 / 22以上 11か月）

| | F0（400条件） | 全5,200条件 |
|---|---|---|
| GVZ 17未満の月の合計がマイナス（＝止めると得） | **89%** | 75% |
| GVZ 22以上の月の合計がプラス | **44%** | 43% |
| 1か月平均（条件の中央値） 17未満 / 17〜22 / 22以上 | −13 / +42 / −14 | −10 / +36 / −14 |

- **「低GVZの月は負けやすい」はほぼ全ての設定に共通**（4MAとも87〜90%）→ 停止ルールは現行設定に限らず効く可能性が高い
- **「高GVZの月は勝てる」は共通ではない**（プラスは半分以下、中央値はマイナス）。高ボラは勝ちも負けも大きくするだけで、勝てるかどうかは設定しだい。現行設定の「22以上で+221」は、2026年に合わせて選ばれた設定であることの影響が大きい（2026年の順位が100条件中1位）
- → GVZは「低いときに休む」根拠には使えるが、「高いときに攻める」根拠にはならない
