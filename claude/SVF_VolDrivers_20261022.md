## 2. 高ボラは続く（再現性が最も高い性質）【事実】
- 月のATR%の自己相関：1か月後 0.72 / 3か月後 0.54 / 6か月後 0.44
- → 一度荒れると数か月続く（金融の一般的な性質「ボラティリティ・クラスタリング」と同じ）。「今月が荒れているなら来月も荒れやすい」は、その場で観測できて後付けにならない

**高ボラの引き金は4種類**（推論）
1. 地政学（中東の戦争・衝突）
2. 米国の通商政策（関税の発表・停止・合意）
3. 金融政策（FRBの人事・利下げ観測・実質金利）
4. 過熱の巻き戻し（最高値の更新 → 追証・利食いで急落）。2025-04 / 2025-10 / 2026-01 はいずれも「最高値 → 急落」の形

その背景には、2022年以降の中銀による大量購入（年約1,000トン）がある。金と実質金利の関係がゆるみ、価格の水準と値幅が大きくなった

## 4. 再現性の評価（推論）
| 性質 | 再現性 | 前もって分かるか |
|---|---|---|
| 高ボラが続く（自己相関0.72） | 高い | ○ 今月のボラで分かる |
| 予定されたイベント（FOMC・CPI・雇用統計・関税の期限・FRB人事） | 高い（日程は決まっている） | ○ カレンダーで分かる |
| 過熱の巻き戻し（最高値の更新・200日線からの大きな乖離） | 中くらい（形は繰り返すが時期は不定） | △ 過熱度で警戒はできる |
| 地政学の突発事件 | 低い（時期は予測できない） | ✕ 起きてから察知する（ニュース） |
| 中銀の買い | 構造的（数年単位） | △ 発表は翌月7日頃なので遅れる |
