# 事前登録：SVF 月次入替（前月上位k条件）— 2026-10-22

この文書をコミットしてから計算する（コミット時刻 = 基準固定の証拠）。結果が悪くても基準は変えず、不採用も記録する。

## 1. 目的
「毎月、前月の成績上位の設定に入れ替える」方法に **選ぶ力** があるか、そして設定の細部を変えても崩れないかを確かめる。合格したときだけEA改修を提案する。

## 2. データ
- `SVF_Monthly_XAUUSD_M15.csv`（Sweep v1.5、2026-10-22受領）。月別純損益（コスト0.50込み・次足始値）
- 使う月：2024-01〜2026-09。2026-10は途中までなので除外
- 評価する月：**2024-02〜2026-09（32か月）**。区間は 2024（2〜12月）/ 2025 / 2026（1〜9月）

## 3. ルール（固定）
1. 各月の初めに、前の1か月（暦月）の純損益で候補を順位付けする
2. 上位からk個を選ぶ。同じ基礎条件（MA×Z閾値×BB復帰×SL）からはフィルター違いを1つまで
3. 同点は idx の小さい方を優先する
4. 選んだk個に等ロット（1/k）を割り当て、その月の純損益の平均をその月の成績とする
- 主設定：**k=4、振り返り1か月**
- 候補の範囲（両方で判定）：
  - U1 = F0（フィルターなし）400条件
  - U2 = F0＋ATR%見送り（0.12/0.14/0.16）1,600条件
  - 低ボラ反転は含めない（`SVF_LowVolRev_Result_20261022.md` で不採用）

## 4. 判定基準（U1・U2の両方で全項目を満たせば合格）
- **R1 利益**：主設定で 2024・2025・2026 の各区間の純損益がプラス
- **R2 選ぶ力**：主設定の32か月合計が、ランダム選択を上回る（片側 p<0.05）
  - ランダム選択：毎月、同じ候補の範囲から基礎条件の重複なしでk=4個を無作為に選ぶ。10,000回、seed=20261022
  - p = (ランダム合計 ≥ 実際の合計 の回数 + 1) / (10,000 + 1)
- **R3 kへの頑健さ**：k=2,3,4,5,6 の全てで32か月合計がプラス。かつ、各区間がプラスのkが5つ中4つ以上
- **R4 リスク**：主設定の最大DD（月末の累積損益で計算）が、同じ32か月での現行EA設定（V1 / Z3 / doten_lock / SL5 / F0）以下

参考（判定には使わない）：全条件の等ウェイト平均、現行EA設定の成績、2025-01〜2026-09（21か月）の値

## 5. すでに見てしまった結果（汚染の開示）
- 2025-01〜2026-09 の21か月について、U1・U2 の k=1/2/4、および重複制約あり・なしの結果を確認済み（`SVF_LowVolRev_Result_20261022.md` §5）
- 「k=4・振り返り1か月」は、前回の事後分析（§4-7）と今回の結果を見て選んだもの
- 2024年の月次入替の成績、k=3/5/6、ランダム選択との比較は、このセッションではまだ見ていない。前回のセッションで見たかどうかは【わかりません】
- → この検証で合格しても、選び方の一部は後付けのまま残る。**汚れていない証拠は、ルール固定後のフォワード（デモ）だけ**
